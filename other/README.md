# Engineering evidence

This directory groups evidence that supports the technical documentation
without making the root README excessively long.

| Path | Purpose |
| --- | --- |
| [`engineering_journal/`](engineering_journal/) | Dated design history and final Engineering Journal PDF |
| [`legacy_national/`](legacy_national/) | Self-contained snapshot of the final National repository, with its original README and layout |
| [`testing/`](testing/) | Test procedures, configurations, measurements and results |

Everything here comes from real work and completed tests. Results that have
not been measured are marked as pending rather than estimated.
